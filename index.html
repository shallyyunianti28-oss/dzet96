Tentang Coding Club

Coding Club hadir dengan tujuan utama sebagai wadah edukatif dan kolaboratif bagi para siswa untuk mengenal serta menguasai dunia pemrograman komputer secara menyenangkan. Melalui kegiatan berkala, klub ini bertujuan untuk membangun pemahaman mendasar hingga tingkat lanjut mengenai logika komputer, bahasa pemrograman, dan pembuatan produk digital seperti situs web, aplikasi bergerak, atau gim sederhana. Selain itu, Coding Club bertugas mendorong lahirnya generasi muda yang inovatif, siap beradaptasi dengan perkembangan teknologi, serta mampu mengubah ide-ide kreatif menjadi solusi digital yang nyata.

Manfaat bergabung dengan Coding Club sangat luas, baik untuk pengembangan kemampuan teknis (hard skills) maupun keterampilan interpersonal (soft skills). Secara teknis, para anggota akan terlatih dalam berpikir kritis, mengasah kemampuan pemecahan masalah (problem solving), dan memahami struktur logika yang berguna di berbagai bidang ilmu. Di sisi lain, proses pengerjaan proyek secara berkelompok akan mengasah kemampuan komunikasi, kerja sama tim, serta kepemimpinan. Pengalaman yang didapat di dalam klub ini juga menjadi bekal berharga untuk persiapan karier di masa depan atau pendidikan tinggi di bidang teknologi informasi.

Kegiatan Coding Club

Kegiatan Coding Club

Kegiatan 1: Belajar HTML

Pada kegiatan ini, anggota belajar dasar-dasar HTML seperti membuat heading, paragraf, gambar, dan link.

Kegiatan 2: Membuat Website

Anggota Coding Club mencoba membuat website sederhana menggunakan HTML dan CSS.

Kegiatan 3: Project Showcase

Anggota menampilkan hasil project website yang sudah dibuat dan menjelaskan proses pembuatannya.
